# 數學放映室：互動影片原型

供教學體驗與意見收集使用，尚未作正式產品驗收。

## 功能

- 十個問題式章節導航、單段重播、逐段學習、0.75×／1×速度及返回首次跳看位置。
- 第2、4、6、7段共四道「想一想，再繼續」，檢查等式關係、分數漏項、驗算及相反運算。
- 錯答提示、重看對應解說並返回同一題、答對後續播，也可略過。答案只留在本次頁面，不儲存或上傳。
- 繁體中文操作介面，原影片為高年級英文一次方程黏土完整版 v02，約5分03秒。

## 本機試用

需 Node.js 22 或更新版本，無外部套件。執行 npm start 後開啟 http://127.0.0.1:4173/ 。用 Ctrl+C 停止。

先觀看開頭，再跳往有「含思考題」標記的章節；試一次錯答、重看解說、返回問題及繼續觀看。也可切換逐段模式，確認停頓是否自然。

## 網頁託管

這是靜態網站，入口為根目錄 index.html，影片使用相對路徑 media/。可將根目錄部署至支援靜態檔案及 MP4 的網站託管服務。上傳 Git 儲存庫本身不等同已開通網站；本次不自動啟用 GitHub Pages。

## 測試與限制

npm test：22項狀態機／字幕邊界測試。來源原型已於Windows內置瀏覽器測試跳段、提示、重播返回及續播；已檢查390px排版，但手機／平板實機與螢幕閱讀器仍待測試。瀏覽器計時不保證系統嚴重卡頓時逐格精準。
